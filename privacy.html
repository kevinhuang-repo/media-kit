隱私權政策

最後更新：2026-11-02

「五分鐘下酒菜」（以下稱本頻道）使用自行開發的內部工具，管理本頻道自己的 Gmail、YouTube、Instagram、Facebook 與 Threads 帳號。這些工具只供本頻道經營者使用，不對外提供服務。

我們存取哪些資料

  • Gmail：讀取本頻道信箱的合作邀約信件，並建立回覆草稿。
  • YouTube：讀取本頻道的影片數據與留言、回覆留言、上傳本頻道的影片。
  • Instagram／Facebook／Threads：讀取本頻道的貼文數據、留言與私訊，並發佈本頻道的影片與回覆。

資料如何使用與保存

  • 資料只用於經營本頻道：整理合作信、回覆觀眾、發佈影片、分析成效。
  • 資料存放在經營者自己的電腦，不出售、不分享給任何第三方，也不用於廣告。
  • 任何對外發送的內容（回信、留言回覆、發片）都由經營者確認後才送出。

Google 使用者資料

本工具使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。

撤銷授權與聯絡

可隨時在 Google 帳戶權限 或 Meta 的應用程式設定中撤銷授權。有任何問題請來信：5minsotsumami@gmail.com

Privacy Policy (English)

"5mins Otsumami" uses self-built internal tools to manage its own Gmail, YouTube, Instagram, Facebook and Threads accounts. The tools are used only by the channel owner and are not offered to anyone else.

Data accessed (collaboration emails, video analytics, comments, messages) is used solely to run this channel, stored on the owner's own computer, never sold or shared with third parties, and never used for advertising. All outgoing content is reviewed by the owner before it is sent.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoke access anytime at Google Account permissions. Contact: 5minsotsumami@gmail.com
